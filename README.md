# ADI OS — GitHub Pages edition

Готовый статический сайт: HTML, CSS, JavaScript. Сборка, Node.js и npm не нужны.

## Размещение на GitHub Pages
1. Создайте новый публичный репозиторий на GitHub.
2. Выберите **Add file → Upload files** и загрузите из этой папки `index.html`, `style.css`, `app.js` и `README.md` именно в корень репозитория (не вложенную папку).
3. Нажмите **Commit changes**.
4. Откройте **Settings → Pages** → **Build and deployment** → **Deploy from a branch**, выберите **main** и папку **/(root)**, затем **Save**.
5. Сайт будет доступен по адресу `https://USERNAME.github.io/REPOSITORY/` (подставьте свой логин и имя репозитория).

Данные хранятся в localStorage конкретного браузера и не синхронизируются между устройствами. Перед очисткой браузера сохраните резервную копию через кнопку внизу сайта. Не используйте на общем компьютере для приватных финансовых данных. Восстановление из JSON в этой версии пока не реализовано.
